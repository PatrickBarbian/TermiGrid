## Descripción general

**TermiGrid** es una aplicación portátil multiplataforma (Rust + `egui`) para la fabricación de cuadros eléctricos. Permite generar regleteros (ej. `-X1`), distribuir numeración multinivel (L, N y fila PE inferior dedicada), editar etiquetas con doble clic en el editor CAD 2D, consultar accesorios compatibles (tapas finales, puentes, señalización, topes), comprobar actualizaciones y exportar archivos `.xlsx` / `.csv` con todas las celdas estrictamente en formato Texto (`@`).

> **Nota:** Este proyecto fue **VibeCoded** por Patrick Barbian con asistencia de IA de **Google Antigravity / Gemini**.
