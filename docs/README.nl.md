## Overzicht

**TermiGrid** is een draagbare cross-platform applicatie (Rust + `egui`) voor de schakelkastbouw. Maak klemmenstroken (bijv. `-X1`), verdeel meerlaagse nummering (L, N en aparte PE-rij), pas teksten direct aan via dubbelklik in de 2D CAD-weergave, bekijk bijpassende toebehoren (afsluitplaten, bruggen, codering, eindsteunen), controleer op updates en exporteer `.xlsx` / `.csv`-bestanden strikt als Tekst (`@`).

> **Opmerking:** Dit project is **VibeCoded** door Patrick Barbian met AI-ondersteuning van **Google Antigravity / Gemini**.
