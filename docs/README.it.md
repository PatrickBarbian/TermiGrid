## Panoramica

**TermiGrid** è un'applicazione portatile multipiattaforma (Rust + `egui`) per la realizzazione di quadri elettrici. Consente di creare morsettiere (es. `-X1`), gestire la numerazione multilivello (L, N, PE con riga PE dedicata), modificare i testi con doppio clic nell'editor CAD 2D, visualizzare gli accessori compatibili (piastre terminali, ponticelli, targhette, fermamorsetti) ed esportare file Excel (`.xlsx`) con tutte le celle in formato Testo (`@`) e verifica automatica degli aggiornamenti.

> **Nota:** Questo progetto è stato **VibeCoded** da Patrick Barbian con il supporto IA di **Google Antigravity / Gemini**.
